## 什么是 IPLC？(International Private Leased Circuit)

**IPLC** 的全称是 *International Private Leased Circuit*（国际私用出租线路）。

简单来说，IPLC 就是电信运营商（如中国电信、中国联通）跨越国界搭建的**点对点物理内网专线**。

```
普通公网线路传输路径：
用户 -> 本地宽带 -> 公网骨干网 -> GFW 防火墙检测 (晚高峰大丢包) -> 境外公网服务器

IPLC 专线传输路径：
用户 -> 国内入口中转服务器 -> [物理内网光纤/海缆专线] -> 境外出口服务器 (不经 GFW, 0 丢包)
```

### IPLC 的核心技术特征：
1. **完全绕过 GFW 防火墙检测**：由于 IPLC 传输的是运营商内网协议数据，流量不经过公网国际出口 gateway，因此不受 GFW 深度包检测 (DPI) 的拦截与干扰。
2. **端到端物理光缆连接**：跨国段采用专门的物理光纤，不与公网普通用户的上网流量竞争带宽。
3. **极低的网络延迟跳动 (Jitter)**：路由路径物理固定，延迟不会像公网那样随高峰期产生剧烈波动。

## 如何识别真正的“真 IPLC”与“假 IPLC”？

市场上部分劣质机场会拿普通公网中转伪装成 IPLC 专线贩卖。你可以通过以下方法进行技术鉴别：

### 1. 路由追踪 (Traceroute) 检测
使用 MTR 或 Traceroute 工具测试入口到出口的节点 IP：
- **真 IPLC**：跳数极少（通常 3-5 跳），中间路由显示为内网保留 IP 地址（如 10.x.x.x 或 172.16.x.x），且不会出现国家防火墙节点的跳数。
- **假 IPLC**：能清晰看到跨国段经过公网骨干网路由，且在晚高峰丢包率猛增。

### 2. 特殊敏感时期的稳定性表现
在每年特殊敏感时期，公网防火墙封锁力度加大，普通公网 IP 会遭遇大面积封锁。如果机场节点**完全不受影响、连通率 100%**，说明其底层大概率确实采用了物理专线。

## IPLC 国际专线科普 FAQ

### Q1：IPLC 专线真的能保证 100% 不会被封锁吗？
跨国 IPLC 物理段绝对不会被 GFW 封锁，因为数据在内网中传输。但如果机场的**国内入口 IP** 被大量举报或遭受 DDoS 攻击，入口可能会暂时断连。优质机场会配置多个 BGP 备用入口来保障可用性。

### Q2：为什么 IPLC 机场套餐的倍率（如 2x / 3x）这么高？
因为 IPLC 的物理光缆租用成本极其昂贵，机场按实际消耗带宽给运营商付费。提高计费倍率是为了覆盖昂贵的专线成本，防止个别用户恶意下载大文件刷爆带宽。
