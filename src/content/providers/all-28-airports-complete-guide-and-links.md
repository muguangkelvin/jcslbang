## 三、28 家机场选购四大防坑铁律

1. **首月一律先买月付**：无论宣传多诱人，新用户第一期务必选择最便宜的月付套餐，测试真实晚高峰满意后再考虑续费。
2. **看清真实倍率**：避免使用 5x/10x 隐形高倍率节点，优先挑选主力节点均为 1.0x 真实倍率的服务商。
3. **搭建主备双订阅**：订阅至少两家基于不同基础设施的服务商（如一条 IPLC 专线 + 一条便宜按量包），避免单点故障。
4. **使用正版官方客户端**：从官方 GitHub 下载 Clash Verge Rev、Sing-box 或 Shadowrocket，切勿使用来源不明的打包客户端。
