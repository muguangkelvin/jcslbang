对于初次在 Windows 电脑上体验科学上网的用户来说，**v2rayN** 是一款兼具稳定与功能全面的必备工具。

为了让新手快速上手，本教程将用最浅显的语言，逐步讲解从软件安装到流畅上网的全过程。

---

## 第一步：准备工作与软件安装

1. 从官方 Releases 页面下载 `v2rayN-With-Core.zip` 压缩包。
2. 在电脑 D 盘或 E 盘新建一个名为 `v2rayN` 的文件夹，将压缩包内容解压至该目录（**注意：路径中严禁包含中文或特殊字符**）。
3. 双击运行 `v2rayN.exe`，右下角任务栏出现 V 字图标即代表启动成功。

---

## 第二步：导入节点与订阅链接

### 方法 A：通过剪贴板批量导入节点
1. 在机场官网复制以 `vmess://`、`vless://` 或 `trojan://` 开头的节点链接。
2. 打开 v2rayN 主界面，在空白区域按下快捷键 `Ctrl + V`，或点击顶部菜单 **“服务器” -> “从剪贴板导入批量 URL”**。

### 方法 B：导入机场订阅 URL（推荐）
1. 在机场后台复制“v2rayN 订阅地址”。
2. 点击 v2rayN 顶部菜单 **“订阅分组” -> “订阅分组设置”**。
3. 点击“添加”，在 URL 栏粘贴订阅链接并保存。
4. 按下 `Ctrl + U` 一键更新获取全部最新节点。

---

## 第三步：设置系统代理与智能分流

1. **测试节点延迟**：选中节点列表，按下 `Ctrl + O` 进行真连接延迟测试，双击选择一个延迟较低的节点。
2. **设置路由分流**：在主界面底部将【路由】设置为 **“绕过局域网及大陆 (geoip:cn)”**，确保国内网站不走代理。
3. **开启系统代理**：在任务栏右下角右键 v2rayN 图标，点击 **“系统代理” -> “自动配置系统代理”**（图标变为红框代表全局生效）。

---

## v2rayN 新手入门指南 FAQ

### FAQ 1：v2rayN 图标变红了，为什么还是打不开 Google？
首先确认选中的节点延迟是否正常。其次，检查电脑系统时间是否准确（右下角时间必须与网络标准时间精确对齐）。

### FAQ 2：不使用科学上网时需要怎么操作？
在任务栏右下角右键 v2rayN 图标，将“系统代理”切换回 **“清除系统代理”**，然后退出软件即可。

---

## v2rayN Windows 保姆级教程总结

掌握了“解压运行 -> 导入订阅 -> 开启路由 -> 勾选系统代理”这四个核心环节，你就能轻松应对 Windows 电脑上的科学上网需求。
