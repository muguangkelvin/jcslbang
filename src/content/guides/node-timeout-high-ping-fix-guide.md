# 节点全部超时与延迟高排查指南：系统时间同步与 DNS 修复

在开启 Clash、Sing-box 或 Shadowrocket 试图访问网页时，许多用户经常遇到节点列表全部显示红色 Timeout 或者延迟高达几千毫秒的情况。节点全红意味着客户端与远端代理服务器之间的通信被阻断。

本文总结了导致节点超时的四大核心原因及对应的排查修复流程。

---

## 根因一：设备系统时间与标准北京时间不同步 (最常见)

**原理**：代理协议（如 VMess、Trojan、Hysteria2）在建立 TLS 安全握手时，会对本地设备的时间戳进行严厉校验。如果你的电脑或手机时间比标准时间快或慢了超过 60 秒，握手将被直接拒绝，导致所有节点全红提示 Timeout。

**修复方法**：
* **Windows**：进入 时间和语言 -> 日期和时间，点击 **立即同步**，并确保开启自动设置时间。
* **Mac**：进入 系统设置 -> 通用 -> 日期与时间，勾选自动设置时间与日期。
* **Android / iOS**：进入设置打开网络提供时间自动同步。

---

## 根因二：本地运营商 DNS 污染与端口阻断

**原理**：国内部分宽带运营商（如移动、长城宽带）可能对机场的域名实施了 DNS 污染，导致客户端无法解析出入口服务器的真正 IP。

**修复方法**：
1. 将电脑网卡的本地 DNS 改为阿里云 DNS 223.5.5.5 或腾讯云 DNS 119.29.29.29。
2. 在客户端设置中开启 Fake-IP 模式，避免本地 DNS 污染。

---

## 根因三：机场套餐已过期或流量耗尽

**修复方法**：登录你的机场后台仪表盘，检查套餐剩余流量是否为 0，以及订阅到期时间是否已过。

---

## 根因四：敏感时期公网 IP 被拦截

**修复方法**：先尝试关闭系统代理，在直连网络下点击更新订阅，拉取机场更新后的最新节点。如果主力节点依然全红，建议切至备用机场线路。
