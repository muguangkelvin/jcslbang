在 Android 安卓平台上，除了大家熟知的 Clash for Android 之外，**Surfboard（俗称“冲浪板”）** 凭藉其**极具现代感的 Material You 设计语言、完美的 Surge 规则兼容性以及极其出色的后台耗电控制**，被无数安卓玩家誉为“安卓端最好的代理客户端之一”。

本文将为你带来 Surfboard 在安卓手机上的手把手安装配置教程。

---

## 为什么选择 Surfboard (冲浪板)？

1. **界面美观且原生支持现代安卓特性**：完美适配 Android 12+ 的动态配色主题与系统桌面小组件 (Widgets)。
2. **原生兼容 Surge 配置格式**：可以直接导入 Surge 的 .conf 配置文件，分流规则极其精准。
3. **极佳的性能与功耗优化**：相比传统的代理应用，Surfboard 在后台静默运行时的 CPU 占用率接近于 0，大幅延长手机续航。

---

## 步骤一：获取并安装 Surfboard

1. **下载渠道**：
   - **Google Play 商店**：直接搜索 **Surfboard** 下载安装。
   - **GitHub 官方 Releases**：访问 Surfboard 官方仓库下载最新的 .apk 安装包。
2. 安装完成后打开软件，给予必要的存储权限与通知权限。

---

## 步骤二：导入机场订阅链接

向 Surfboard 导入节点非常简单：

```mermaid
flowchart LR
    A[复制机场的 Surfboard / Surge 订阅 URL] --> B[打开 Surfboard 软件]
    B --> C[点击底栏的 配置 Profiles 菜单]
    C --> D[点击右下角 + 号 -> 从 URL 导入]
    D --> E[粘贴 URL 并点击下载]
    E --> F[选中刚下载的配置文件]
```

1. 在机场后台复制 **Surfboard 订阅链接**（或通用 Surge 4/5 订阅链接）。
2. 打开 Surfboard，切换到底部导航栏的 **“配置” (Profiles)** 标签。
3. 点击右下角的 **+** 按钮，选择 **“从 URL 导入” (Import from URL)**。
4. 在输入框中粘贴订阅 URL，点击确定。软件会自动下载并解析出节点与规则。
5. 在配置列表中，点击刚下载好的配置文件，使其左侧出现激活标记。

---

## 步骤三：启动代理服务与策略组切换

1. 切换到底部导航栏的 **“控制台” (Outbound / Policy)** 标签。
2. 根据个人需求选择路由模式（推荐使用 **Rule 规则分流模式**）。
3. 在展开的“节点选择”、“流媒体解锁”等策略组中，点选你希望使用的代理节点。
4. 点击界面右下角的 **蓝色播放按钮** 开启代理。
5. 首次运行时，安卓系统会弹窗提示“Surfboard 申请建立 VPN 连接”，点击 **“确定”** 允许。

---

## Surfboard 高级特性：添加控制中心快捷开关 (Tile Window)

为了无需打开 App 即可快速开关代理：
1. 下拉安卓手机系统通知栏与控制中心。
2. 点击编辑图标（小铅笔）。
3. 在候选开关列表中找到 **“Surfboard” 快捷磁贴**，将其拖拽至常用开关区域。
4. 此后点击该快捷图标，即可一键开关科学上网代理。

## Surfboard 配置常见问题 (FAQ)

### Q1：为什么导入 Clash 订阅链接到 Surfboard 会提示格式错误？
Surfboard 基于 Surge 的配置文件结构开发，无法直接读取 Clash 的 YAML 语法。请在机场后台复制明确标有 **Surfboard** 或 **Surge** 的订阅链接；或通过订阅转换工具切换输出格式。

### Q2：开启 Surfboard 后，手机连接 Wi-Fi 提示“已连接但无法访问互联网”？
这是安卓系统的正常检测机制。代理接管网卡后，系统向谷歌域名发起的 Ping 受到分流策略影响。只要实际网页能正常打开，即可忽略该系统提示。
