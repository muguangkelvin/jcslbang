在 iOS 代理客户端中，**Stash** 凭借其对 **Clash YAML 配置文件的 100% 原生兼容能力**，成为了无数习惯电脑端 Clash 规则用户的首选苹果手机应用。

本文将为你深度讲解 Stash 在 iOS 端的进阶使用技巧，从 YAML 配置文件的高级修改到本地覆写（Override）与网络调试。

---

## Stash 的三大核心技术优势

1. **零成本迁移 Clash 配置**：无需经过繁琐的第三方订阅转换，直接在 Stash 中导入电脑端的 `.yaml` 订阅文件即可无缝运行。
2. **模块化本地覆写 (Override)**：允许用户在不破坏机场原配置的前提下，追加本地自定义规则组或修改 DNS 解析。
3. **Surge 级别的脚本重写扩展**：支持 JavaScript 脚本拦截与 HTTP(S) MITM 解密，实现精细化应用去广告。

## 进阶技巧一：在 Stash 中使用 Override 覆写机场配置

如果你希望在保留机场官方订阅自动更新的同时，加入自己专属的规则（如 Telegram 走特定节点、指定内网 IP 直连），推荐使用 **Override** 功能。

### 操作步骤

1. 打开 Stash，进入【覆写】(Override) 页面。
2. 点击右上角 `+` 创建本地覆写文件。
3. 在覆写规则中添加你个人需要的域名直连或代理条目（例如指定特定国内域名走直连）。
4. 开启覆写开关后，即使机场后续更新订阅，你的个人规则也不会丢失。

## 进阶技巧二：配置 Web 控制台远程调试

Stash 内置了功能强大的网页版控制台 (Web Dashboard)：

1. 在 Stash【设置】中开启 **“Web 控制台”** 选项，并设置访问密码。
2. 确保电脑与 iPhone 处于同一个 Wi-Fi 局域网下。
3. 在电脑浏览器中输入手机提示的 IP 与端口（如 `http://192.168.1.105:9090`）。
4. 在大屏电脑上直观监控手机的实时流量图谱、连接日志并批量测试节点延迟。

## Stash iOS 进阶配置 FAQ

### Q1：Stash 导入 Clash 订阅后某些节点显示“未知协议”怎么办？
通常是因为机场订阅中包含了 Stash 当前版本尚未集成的第三方自定义协议扩展。检查并更新 Stash 至 App Store 最新版本即可支持最新的 Mihomo / VLESS 语法。

### Q2：开启 Stash 代理后手机耗电明显增加怎么解决？
在 Stash【设置 -> 局域网连接】中关闭不必要的局域网共享，并在【高级设置】中关闭全局 HTTP 日志记录，可显著降低 CPU 开销。
