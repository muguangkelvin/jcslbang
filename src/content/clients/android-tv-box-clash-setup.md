# 安卓电视盒与电视墙安装 Clash 教程：大屏观看 Netflix / YouTube 4K

在客厅大屏（如索尼电视、小米电视盒子、NVIDIA Shield TV 或 Chromecast）上观看 YouTube 4K 和 Netflix，能够带来极致的视听体验。然而，电视端 Android TV 系统没有手机那样的触控屏幕，使用遥控器配置代理软件往往遇到光标无法点击、订阅复制困难等问题。

本文将针对电视大屏环境的特殊性，提供一套专为电视盒优化的 Clash 部署方案。

---

## 智能电视与电视盒系统的底层要求

在正式安装前，请确认电视设备满足以下硬件与系统条件：

* **系统版本**：Android 7.0 (API Level 24) 或更高版本的 Android TV / Google TV 系统。
* **未知来源安装许可**：进入设置中的安全与限制，允许安装未知来源应用，以便安装侧载的 APK 文件。
* **内存建议**：建议电视盒运行内存 (RAM) 在 2GB 以上，避免代理内核在后台运行时因内存不足被系统强行终止。

---

## 解决电视遥控器交互：软件选择与 APK 传输

电视侧无法直接长按复制 URL 文本，且普通移动版 Clash 的图形界面没有针对 D-Pad 遥控器焦点做适配。

### 1. 软件版本挑选
推荐下载专为电视屏优化的 Clash for Android TV 适配版 或 Sing-box Android TV。这类版本在选项框之间可以通过遥控器的上下左右方向键轻松聚焦。

### 2. 将 APK 传输至电视侧
* **U 盘安装**：在电脑端下载好 APK 放入 U 盘，插至电视盒后使用“小白文件管理器”点击安装。
* **局域网无线传输**：在电视和手机上同时安装 Send Files to TV 软件，在同一个 Wi-Fi 环境下将 APK 一键推送到电视侧。

---

## 大屏环境下的三种极速导入订阅方法

考虑到在电视屏幕上输入长串 URL 极其痛苦，建议使用以下三种辅助方式导入机场订阅：

### 方式一：扫描屏幕二维码导入
打开手机端集成了订阅信息的二维码，在电视端 Clash 中选择扫描二维码功能，将手机摄像头或电视自带的摄像头对准扫码即可瞬间拉取节点。

### 方式二：局域网 Web 控制台推送 (External Control)
1. 启动电视端 Clash，进入设置找到 External Control 绑定的局域网 IP（例如 192.168.1.105:9090）。
2. 在电脑或手机浏览器中打开 Clash Web Dash 控制台，输入电视端 IP 进行远程连接。
3. 在控制台中直接粘贴机场提供的 Clash 订阅链接，点击刷新拉取。

### 方式三：局域网中转文件共享
利用电视盒内置的 SMB 共享或 FTP 功能，将电脑上配置好的 config.yaml 配置文件直接替换进电视盒的临时存储路径。

## 大屏看 Netflix 4K 与 403 报错优化

电视端 Netflix 客户端相比手机版拥有更严厉的风控机制，不仅校验广域网出口 IP 的原生属性，还会校验 Widevine L1 硬件安全等级。

1. **选择原生住宅双 ISP 节点**：在节点列表中挑选标记有原生 IP 或流媒体解锁的节点，避免使用广播 IP 导致 Netflix 弹出 NW-2-5 或 403 报错。
2. **强制开启 TUN 模式与 Fake-IP**：在电视端设置中勾选 TUN Mode，接管电视上迪士尼、油管等所有 App 的 UDP 流量。Fake-IP DNS 能够大幅缩短大屏播放器预加载 4K 视频时的握手耗时。
3. **设置开机自启 (Boot Completed)**：在 Clash 设置中勾选开机自动运行，确保每次点亮电视后无需手动打开软件即可直接观看无界大屏影音。
