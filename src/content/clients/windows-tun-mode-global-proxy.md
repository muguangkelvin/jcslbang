在 Windows 操作系统中，普通的“系统代理”（HTTP/SOCKS5 局部代理）只能作用于浏览器以及支持代理设置的常规软件。

然而，**外服 PC 游戏、CMD/PowerShell 命令行终端、Git 客户端以及微软商店 (UWP) 应用** 往往会绕过系统代理，导致流量依然直连并连接超时。

解决这一痛点的终极方案就是开启 **TUN 虚拟网卡模式**。

---

## TUN 模式的工作机制

TUN 模式会在 Windows 系统内创建一张虚拟网络适配器 (Virtual TUN Adapter)。

通过修改操作系统底层路由表，将所有应用程序发出的 IPv4/IPv6 IP 数据包无差别接管并送入代理内核分流处理，实现真正的**底层全局网络接管**。

---

## 在 Clash Verge Rev / v2rayN 中开启 TUN 模式的步骤

### 方法一：在 Clash Verge Rev 中开启
1. 以 **管理员身份** 运行 Clash Verge Rev。
2. 进入【设置】(Settings) 页面。
3. 找到 **TUN 模式 (TUN Mode)** 开关并将其开启。
4. 初次开启会自动安装 `wintun.dll` 虚拟网卡驱动，弹出安全提示时点击“允许”。

### 方法二：在 v2rayN 中开启
1. 确保以管理员权限启动 v2rayN。
2. 在底部状态栏将系统代理设置为 **“开启 TUN 模式”**。
3. 在【路由设置】中确认 TUN 模式的流量分流规则正常运行。

## TUN 模式开启注意事项与 FAQ

### Q1：开启 TUN 模式后电脑无法上网或者网卡报错？
这通常是因为与其他虚拟网卡（如 VMware、VirtualBox 或第三方 VPN 驱动）发生了网卡冲突。建议禁用不必要的虚拟网卡后重试。

### Q2：TUN 模式是否可以代替游戏加速器？
如果所选的代理节点是低延迟、低丢包的 IPLC 专线，TUN 模式完全可以替代游戏加速器降低外服游戏延迟；若节点为普通公网线路，丢包率可能相对较高。

## Windows TUN 模式教程总结

启用 TUN 虚拟网卡模式彻底打破了传统 HTTP 代理的局限，为 Windows 提供了全覆盖、无死角的高性能代理转发能力。
