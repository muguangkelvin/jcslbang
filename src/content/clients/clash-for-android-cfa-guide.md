# Clash for Android (CFA) 保姆级教程：安卓端订阅导入与 TUN 模式

Clash for Android (简称 CFA) 是 Android 平台上最经典、功能最完善的基于规则的代理客户端之一。它能够根据域名和 IP 自动识别流量，实现“国内应用直接连、国外网站走专线”，在保证访问速度的同时节省机场套餐流量。

本文将手把手带你完成从安装、订阅导入到开启 TUN 模式的全套流程。

---

## 安装前准备与正版 APK 获取

由于国内应用商店均未上架科学上网软件，切勿从不知名的第三方下载站获取修改版 APK，防止被植入恶意木马或广告弹窗。

* **官方 Release 渠道**：从 ClashForAndroid 官方 GitHub Release 页面下载干净的安装包。
* **架构选择**：通用手机建议选择 v8a 架构（例如 ClashForAndroid-v2.5.12-premium-arm64-v8a.apk），能够最大化发挥现代 64 位 CPU 的解密性能。
* **系统权限放行**：安装时如果提示未知来源应用，点击允许；首次启动时系统会弹出请求创建 VPN 连接的对话框，务必点击同意。

---

## 导入机场订阅配置步骤

要使用 CFA 访问网络，首先需要把机场的节点和分流规则拉取到软件中：

1. **复制订阅**：登录你的自营机场后台，在客户端导入区域找到一键导入 Clash 订阅或复制完整的 Clash 订阅链接。
2. **新建配置**：打开 CFA 首页，点击配置 (Profiles) -> 右上角加号 (+) -> 选择 URL。
3. **填写参数**：
   * **名称**：填写机场名称（例如：灵动云主力配置）。
   * **URL**：粘贴刚才复制的机场订阅链接。
   * **自动更新间隔**：建议设置为 1440 分钟（即 24 小时自动同步一次最新节点）。
4. **保存与选中**：点击右上角保存图标，回到配置列表，点击刚才新建的配置卡片，使其左侧出现绿色指示条，代表当前配置已被激活。

## 启动代理与规则分流模式切换

回到 CFA 首页，点击中间的“点此启动 (Stopped)”按钮。当状态变为“已连接 (Running)”并且通知栏出现钥匙小图标后，即代表代理已经成功生效。

进入代理 (Proxy) 菜单，可以在顶部切换三类运行模式：
* **规则 (Rule)**【推荐】：系统会自动判断流量。百度、微信、淘宝等国内 App 不走代理；Google、YouTube、Twitter 自动走国外节点。
* **全局 (Global)**：强制手机上所有网络请求全部走同一个国外节点，适合调试某些风控严格的网站。
* **直连 (Direct)**：所有流量不经过代理服务器，相当于关闭科学上网。

在规则模式下，你还可以针对不同地区（如香港、日本、美国）或用途（如 Netflix 解锁、ChatGPT 专属）分别选择不同的节点。

## TUN 模式与绕过应用分流技巧

某些游戏（如 Steam 移动端、Apex 英雄）或命令行工具不走标准的系统代理 HTTP 端口。此时需要在设置中开启 TUN 模式。

### 1. 开启 TUN 虚拟网卡
进入设置 -> 覆写 (Override) -> TUN 模式，将开关打开。TUN 模式会在 Android 底层挂载虚拟网卡，强制接管手机上所有的 TCP 与 UDP 数据包，对于降低外服游戏延迟有显著效果。

### 2. 设置应用分流 (Bypass Apps)
如果你不希望某些国内敏感应用（如手机银行、个人云盘）受到代理软件干扰：
进入设置 -> 关联 (Network) -> 绕过应用，勾选需要直连的国内 App，被勾选的软件流量将完全绕过 Clash，由手机宽带或 5G 移动网络直接传输。
