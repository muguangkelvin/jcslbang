# 安卓手机后台自动杀死 Clash / Surfboard 进程防杀设置指南

许多安卓手机用户在开启 Clash for Android 或 Surfboard 后，经常遇到锁屏十几分钟或者切换到其他应用后代理自动断开的情况。这通常并不是机场节点故障，而是国产手机操作系统为了提升续航，采用了激进的后台内存清理策略与省电机制。

---

## 安卓系统激进后台清理机制与代理中断原因

当 Clash 或 Surfboard 运行在后台时，系统会将其识别为非前台高耗电应用。如果没有在系统层赋予长期常驻与免省电优化权限，安卓系统的 Doze 睡眠模式或 RAM 清除策略就会自动终止代理进程与虚拟网卡 (TUN) 接口，导致网络瞬间中断。

要彻底解决该问题，必须同时在操作系统设置和代理软件内部进行“双重锁定”。

---

## 通用基础配置：开启应用锁与允许后台高耗电

无论你使用的是哪种品牌的安卓手机，以下三项属于所有系统的通用防杀基础设定：

1. **多任务界面锁定应用**：打开手机的多任务后台（任务切换界面），长按 Clash 或 Surfboard 卡片，点击“小锁”图标将其锁定，防止一键清理后台时被顺手杀掉。
2. **关闭电池优化**：进入系统的 `设置 -> 应用管理 -> 权限管理 -> 电池优化`（或后台高耗电），找到对应的代理软件，将策略从“智能控制”改为“不限制”或“允许后台高耗电”。
3. **允许自启动与关联启动**：勾选允许应用开机自启和被系统唤醒，确保手机休眠重启后代理服务不会遗失。

## 主流国产手机系统防杀配置指南

不同厂商对后台权限的控制菜单位置有所差异，以下列出各大品牌最新的设置步骤：

### 小米 HyperOS / MIUI 策略
进入 `设置 -> 应用设置 -> 应用管理 -> Clash/Surfboard -> 省电策略`，强制选择 **无限制**。随后在 `自启动管理` 中开启允许自启动。

### 华为 / 荣耀 HarmonyOS 策略
进入 `设置 -> 电池 -> 耗电排行 -> Clash/Surfboard -> 启动管理`，关闭“自动管理”，开启 **允许自启动、允许关联启动、允许后台活动** 三项开关。

### OPPO / 一加 ColorOS 策略
进入 `设置 -> 应用 -> 应用启动管理`，关闭自动管理，手动勾选允许后台运行。并在 `电池 -> 后台耗电管理` 中勾选允许深层耗电。

### vivo / iQOO OriginOS 策略
进入 `设置 -> 电池 -> 高耗电管理`，勾选允许 Clash/Surfboard 持续运行。并在 `应用与权限 -> 权限管理 -> 自启动` 中打开开关。

## Clash与Surfboard软件端持久化设定

除了手机系统的设置外，软件内部的设置同样至关重要：

* **开启常驻通知栏**：在软件设置中打开“显示通知栏”或“前台服务 (Foreground Service)”。Android 规定拥有前台通知的应用具有更高保活优先级。
* **开启开机自动连接**：勾选“Boot Completed”，手机重新开机后会自动挂载 TUN 网卡与分流规则。
* **启用 TUN 模式网络接管**：优先选择 TUN 模式而非 HTTP 代理模式，网卡级别的连通性在后台相比应用层代理更不易被卸载。

## 验证后台保活生效与排查掉线测试

完成配置后，可以通过以下测试验证防杀效果：

1. 启动代理软件并连接节点。
2. 锁定手机屏幕放置 20 分钟以上。
3. 解锁手机并立即打开浏览器或 YouTube，检查顶部状态栏的 key/VPN 状态图标是否依然存在，页面能否秒开。

如果仍然偶发掉线，建议检查是否安装了第三方的“手机管家”或安全卫士软件，并将其内部的清理名单一并排除。

## 安卓代理后台保活常见疑问 FAQ

### Q：锁定后台并允许高耗电会不会导致手机电池发热或续航大幅下降？
答：代理软件在后台主要进行网络数据包的解密与规则路由，CPU 占用极低。只要不开启持续的日志抓包，日常后台常驻增加的耗电量通常微乎其微（每日约 1%-3%）。

### Q：为什么已经关闭了电池优化，小米手机锁屏后还是掉线？
答：小米系统拥有神隐模式与超级省电机制。请检查 `安全中心 -> 性能与电池 -> 右上角设置 -> 锁屏后清理内存`，确保将其设为“从不”。

### Q：Surfboard 和 Clash 两者哪个在安卓后台更稳定？
答：Surfboard 底层对 Android 前台服务和 TUN 网卡做了深度优化，在国产系统的保活表现略优于旧版 Clash for Android。建议经常掉线的用户尝试切换至 Surfboard 或 Sing-box。
