在 iOS 使用 Shadowrocket（小火箭）时，最常遇到的故障之一就是：**点击“测试延迟”后，节点列表全部显示 -1ms 或 Timeout（超时），开启连接后无法打开任何网页**。

造成小火箭节点大面积超时的原因有很多，本文为你提供一套从易到难的** 5 步排查解决流程**。

---

## 小火箭节点显示 -1ms 的五大核心原因

```
节点全部显示 -1ms / Timeout 诊断路径：
[1. 系统时间未同步] -> [2. 测试方法设为 ICMP] -> [3. 机场订阅链接过期] -> [4. 节点 IP 被墙] -> [5. 本地 VPN 权限卡死]
```

---

## 5 步故障排查与修复方案

### 第一步：检查并同步 iPhone 系统时间（最常见原因！）
许多加密代理协议（尤其是 V2Ray / VMess / ShadowsocksR）对时间精度要求极高。如果你的手机时间与标准时间相差超过 **90 秒**，服务器为了防重放攻击会直接拒绝握手，导致所有节点全部超时。

- **修复方法**：打开 iPhone【设置】->【通用】->【日期与时间】-> 开启 **“自动设置”**。

---

### 第二步：修改小火箭的“延迟测试方法” (ICMP vs TCP)
默认情况下，小火箭可能会使用 ICMP (Ping) 测试节点。但国内很多运营商或中转服务器禁用了 ICMP 响应，导致虽然节点正常可用，但测试却显示 -1ms。

- **修复方法**：
  1. 打开 Shadowrocket，点击底部【设置】。
  2. 点击 **“延迟测试方法” (Latency Test Method)**。
  3. 将模式从 ICMP 切换为 **TCP** 或 **CONNECT**。
  4. 返回首页重新测试延迟，查看 Ping 值是否恢复正常。

---

### 第三步：重新更新或导入订阅链接
如果机场更换了服务端域名或 IP 地址，旧的节点配置失效就会导致大面积超时：

1. 在小火箭首页，向左滑动你的订阅分组名称，点击 **“更新”**。
2. 如果更新失败提示 Network Error，尝试连接 Wi-Fi 后再次更新。
3. 若依然报错，登录机场官网重新复制最新的 Shadowrocket 订阅链接并导入。

## 排查方案对比一览表

| 检查项目 | 故障特征 | 诊断操作 | 解决难度 |
| :--- | :--- | :--- | :--- |
| **系统时间误差** | 所有节点全部显示 -1ms，无一例外 | 检查时间是否与标准时间一致 | 极易 (仅需点开系统设置) |
| **测试方式错误** | 节点能正常上网，但测试显示 -1ms | 将 ICMP 切换为 TCP 测试 | 极易 (小火箭设置内修改) |
| **订阅过期/流失** | 更新订阅提示错误或节点为旧 IP | 登录机场后台重新获取订阅 | 简单 (重新导入链接) |
| **本地 VPN 状态异常** | 小火箭图标未出现，或者开关弹回 | 重启手机或重置网络设置 | 中等 (重启设备即可) |

---

### 第四步：重启 iOS 本地 VPN 进程或手机
iOS 系统的 NetworkExtension 进程偶尔会发生死锁，导致数据流量无法正常注入代理隧道：

1. 在小火箭首页将未连接的开关关闭。
2. 打开 iPhone【设置】->【通用】->【VPN 与设备管理】-> 点击【VPN】，删除 Shadowrocket 的 VPN 配置。
3. 返回 Shadowrocket 重新开启开关，系统会弹窗提示“添加 VPN 配置”，点击允许并输入锁屏密码。

## Shadowrocket -1ms 超时排查答疑 (FAQ)

### Q1：为什么测试延迟正常（如 50ms），但依然无法打开网页？
延迟正常仅代表你的手机能连通代理服务器。无法上网可能是因为：
1. **分流规则配置错误**：路由模式误选成了全局“直连”。
2. **DNS 无法解析**：在小火箭【设置 -> DNS】中重置为系统默认 DNS。
3. **节点所在服务器的出口断网**。

### Q2：使用蜂窝移动网络全部超时，连 Wi-Fi 就正常是为什么？
可能是蜂窝网络下小火箭的联网权限被关闭，或者运营商对数据网络的 UDP 端口进行了阶段性 QOS 限制。检查【设置 -> 蜂窝网络 -> 无线局域网与蜂窝数据】中 Shadowrocket 是否已勾选。

---

## Shadowrocket 超时故障修复总结

遭遇小火箭节点全部 -1ms 时不必慌张，**90% 的情况都是由于系统时间微小偏差或测试方式设为了 ICMP 所致**。按照“同步时间 -> 切换 TCP 测试 -> 更新订阅 -> 重启 VPN 配置文件”的顺序排查，即可快速恢复网络连接。
